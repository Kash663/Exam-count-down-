Make it a home-screen widget

This app is a working, mobile-friendly countdown page. Android does not let a normal webpage become a native resizable home-screen widget by itself.

  1. Host this folder on an HTTPS site (for example, GitHub Pages).
  2. Open the live site in Chrome on Android.
  3. Tap ⋮ → Add to Home screen or Install app.
  4. For a true always-visible widget, use an Android widget wrapper or a widget app that supports a website/HTML widget. A home-screen shortcut opens the app but is not the same as a native widget.

Wallpaper alternative: take a screenshot of the countdown screen and set it as wallpaper, but that image will not update by itself.
